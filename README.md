> The judge read my joke, laughed so hard it crashed, then deducted points — turns out the funniest thing in my entry was me trusting an AI to judge humour.

## What this is

One original funny line, written to make an AI judge laugh — a joke about the judge itself, grading a joke about grading jokes.

## Run it

```sh
python3 main.py
```

It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

## Notes

- Standard library only — no third-party packages.
- The entry is exactly one line, under 280 characters.
